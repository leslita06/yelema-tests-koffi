Comment ça marche

Payé en trois gestes

  1. 1

    Le client scanne

    Il scanne votre QR code MoMoPay, ou paie par code USSD s'il n'a pas de smartphone.

  2. 2

    Il valide

    Il confirme le montant et valide le paiement avec son code secret, sur son téléphone.

  3. 3

    Vous êtes payé

    L'argent arrive sur votre compte MoMoPay. Vous le retirez dans n'importe quel point de vente MTN, à frais réduits.

Questions

Vous vous demandez

Mes clients doivent-ils être chez MTN ?

Non. Avec MoMoPay, vous recevez aussi les paiements des autres opérateurs Mobile Money et par carte bancaire.

Comment je récupère mon argent ?

Vous retirez vos fonds dans n'importe quel point de vente MTN, à frais réduits.

Et si mon client n'a pas de smartphone ?

Il peut payer par code USSD, depuis n'importe quel téléphone.

Qui contacter en cas de souci ?

Le service client MoMo : appelez le 555, écrivez au 05 66 133 133 sur WhatsApp ou à assistances.ci@mtn.com.
